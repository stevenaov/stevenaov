  - Construido en **un solo archivo HTML/CSS/JS** sin frameworks ni imágenes externas: textura de papel arrugado generada proceduralmente, ilustraciones SVG propias, tema claro/oscuro, **Modo Garabato** interactivo para dibujar sobre la página y optimización de renderizado para pantallas de **165Hz**.

  - Librería open-source de **24 componentes** en **React 18 + TypeScript estricto + Vite 6**, inspirada en el nivel de detalle de Linear, Vercel y Framer, construida con **design tokens CSS puros y cero dependencias en runtime**.
